# Embodied Companion Health

> **Can a long-term embodied AI companion support wellbeing by noticing meaningful changes from a person's own baseline?**

Embodied Companion Health is a public research-concept project exploring long-term embodied AI companionship, behavioral continuity, personal-baseline wellbeing support, consent, privacy, cyber-physical safety, and maintainability.

This site is the readable documentation view of the public GitHub repository. The repository remains the source of truth for version history, issues, pull requests, releases, licensing, and research discussion.

## Core hypothesis

A companion that is continuously present may be able to support wellbeing with less friction by learning a user's ordinary patterns and surfacing meaningful deviations — **without pretending to be a doctor**.

The current public work focuses on four areas:

1. **Long-term embodied companionship** — continuity across days, contexts, model updates, and eventually hardware changes.
2. **Personal-baseline wellbeing support** — noticing persistent deviation from the user's own recent normal while representing uncertainty.
3. **Trust, consent, safety, and privacy** — permissions, revocation, safety-critical separation, data minimization, cyber-physical security, and lifecycle control.
4. **Embodied HCI and maintainability** — determining where physical presence adds measurable value and how close-contact systems remain inspectable and maintainable.

## Current status

The project is at the **concept and research-framing stage**. The near-term implementation target is a low-cost avatar-based Stage A demonstrator used to test continuity, consent, baseline-aware support, proactivity, and model migration before custom robotics is justified.

This is **not** a medical device, diagnostic system, treatment system, or production robotics platform.

## Public / private boundary

The working rule is:

> **Public: what, why, and how to evaluate. Private: exactly how to build, protect, and commercialize.**

Implementation-sensitive mechanisms, patent-candidate details, exploitable security details, sensitive raw human data, and commercial strategy remain outside the public repository unless deliberately reviewed for release.
