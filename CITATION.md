# Citation and provenance

If this project influences research, design, writing, or a later implementation, please cite or link back to this repository where practical.

For the first public concept release, a simple citation is:

> **Embodied Companion Health**, `serevy/embodied-companion-health`, public concept release `v0.1-concept`, 2026.

Until a DOI or archival record is created, please include:

- the repository name;
- the repository URL;
- the release tag or commit used;
- the access date when relevant.

## Why provenance matters

The goal of this project is not to prevent independent work on embodied AI companions. It is to make the research framing, open questions, and evaluation ideas traceable so that later work can distinguish inspiration, reuse, independent development, and validated evidence.

The repository license governs reuse of covered copyrighted material. It does not imply ownership of every independently developed idea or implementation in the broader research area.

If a future release is archived with a DOI, this file should be updated with the preferred formal citation.
